YouTube Music Party Server

Party server URL: https://music.ytparty.my.id

Install the extension from the Chrome Web Store. Chrome handles updates automatically.

See setup and support for full instructions.

Local Development Installation

For a locally built extension:

  1. Build the extension from the project source.
  2. Open Google Chrome.
  3. Go to chrome://extensions/ in the address bar.
  4. Enable Developer mode (toggle in the top-right corner).
  5. Click "Load unpacked".
  6. Select the apps/extension/dist folder.
  7. The extension will be installed and ready to use.

Tip: Click the puzzle icon 🧩 in the toolbar to manage extensions.

How to Use this Bot

  1. Add @xmsc_bot to your Telegram group.
  2. Run the command /register in the group chat.
  3. Open YouTube Music and click "Join Room" in the sidebar.
  4. Enter the room ID from the bot and use https://music.ytparty.my.id as the party server URL.

How to Add Queue

  1. Find the music you want to add to the queue.
  2. Tag @xmsc_bot in the group chat, followed by "search [music name] here" (e.g. @xmsc_bot search Shape of You here).
  3. Bot will display the results of the search. Click the "Add to queue" button next to the desired result.
  4. Then, run the command /play in the group chat to play the music from the queue.
