The web room

Guests can find songs, see what’s playing, and vote to skip without installing anything. The music plays in the host’s YouTube Music tab.

Open web room

The host’s extension

See the current track and upcoming requests, control playback, or change player settings without opening the room.

Connect a player

Copy the Room ID from the web room’s settings or from Telegram’s /register reply, then paste it into the extension.

Read the setup guide

The queue in Telegram

Use /queue to check what’s coming up without leaving the chat.

Votes, history, and room controls

Vote to skip, look back at recent plays, or review the room’s settings and stats.

Find a song in the chat

Type @xmsc_bot Justin Bieber Baby, then select a result. The selected song offers Add to Queue.

Your request joins the queue

Queue a song for later, or use Play Next if the host has enabled it. Your requests show up in the player too.

Start the Telegram bot

Open @xmsc_bot and send /start to see the setup instructions.
