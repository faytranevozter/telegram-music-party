Setup and support

Getting started

  1. Install the extension from the Chrome Web Store.
  2. Open music.youtube.com and click Join in the left sidebar.
  3. Enter your room ID and the party server URL.
  4. Add the bot to your Telegram group and control playback from there.
One device plays per room. Joining from a second browser or tab replaces the first one — this is enforced by the server.

Connection problems

  • The party URL must be reachable from your browser. Use an https:// URL in production.
  • If you run your own backend, make sure it is running and that the URL is correct.
  • The extension cannot reach a server on a different machine using localhost.

Playback not responding

  • Reload the YouTube Music tab after installing or updating the extension.
  • Confirm the tab is joined — the sidebar entry point shows the current room.
  • Leave and rejoin the room to reset the session.

Get help

Report bugs or ask questions on the issue tracker. Include your browser version, the extension version shown in the popup, and what you expected to happen.
