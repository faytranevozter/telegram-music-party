Setup and support

Getting started

  1. Install the extension from the Chrome Web Store. Chrome handles updates automatically.
  2. Add @xmsc_bot to your Telegram group and run /register to get the room ID.
  3. Open music.youtube.com, then open the extension popup from your browser toolbar.
  4. Enter the Room ID. The party server defaults to https://music.ytparty.my.id; expand Advanced / custom server to use your own trusted server.
  5. Click Join Room. The music tab refreshes, which may briefly interrupt playback. Wait for Connected, then control playback from Telegram.
One device plays per room. If another device owns the room, joining shows Room busy rather than replacing the current player. Leave the room on that device before clicking Retry join.

You can close the popup while joining; joining continues in the music tab. Reopen the popup to see the result. The YouTube Music sidebar's Join Room prompts are still available as an alternative.

Connection problems

  • No tab: click Open YouTube Music, wait for it to load, then reopen the popup to join.
  • Bridge unavailable: reload the YouTube Music tab, then click Retry connection in the popup. After installing or updating the extension, existing music tabs may need a refresh.
  • Server unreachable: check the party URL and network connection. The default is https://music.ytparty.my.id. Use an https:// URL in production; HTTP URLs such as http://localhost:3000 are supported for local development.
  • Admission not confirmed: waiting is limited to 30 seconds. Check the room ID from /register and the server URL, then click Retry join or edit the form and click Join Room again. A timeout does not prove the room does not exist.
  • Saved server URLs are preserved, including custom ports and paths. While connected, use Leave room before joining another room or changing servers. When not admitted, the form remains available to correct the configuration.
  • If you run your own backend, make sure it is running and that the URL is correct.
  • The extension cannot reach a server on a different machine using localhost.

Playback not responding

  • Reload the YouTube Music tab after installing or updating the extension.
  • Confirm the popup shows Connected and the expected room ID. Connecting… means admission is still pending.
  • If several YouTube Music tabs are open, activate the one you want to control before opening the popup. The popup follows that selected tab; updates from other tabs do not replace its status.
  • Leave and rejoin the room to reset the session.

Get help

Report bugs or ask questions on the issue tracker. Include your browser version, the extension version shown in the popup, and what you expected to happen.
