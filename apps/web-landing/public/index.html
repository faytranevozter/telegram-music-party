One tab. One room.
Whole group listening.

Connect a YouTube Music tab to a room and let a Telegram group control the queue together.

Get started View source
The browser extension only runs on music.youtube.com. It does not collect account credentials, passwords, or personal browsing history. Not affiliated with YouTube, Google, Chrome, or Telegram.

How it works

  1. Install the extension, then open music.youtube.com.
  2. Click Join on the YouTube Music page.
  3. Enter your room ID and the party server URL you want to use.
  4. Use the Telegram bot in your group to control playback and the queue.

Self-hosting

This is an open-source project. The extension connects to the party server URL you provide, so you can run the backend yourself and keep your data under your own control. See the project repository for setup instructions.
