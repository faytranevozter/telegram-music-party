You bring the tab.
The group brings the tunes.

Set up the player in desktop Chrome. Once it’s connected, friends can join from their browsers.

  1. Install the extension

    Add to Chrome from the Chrome Web Store. Chrome handles updates automatically.

  2. Create a web room

    Open the web room, choose a room name and nickname, then find your Room ID under Room info & settings.

  3. Open your player

    Open YouTube Music, then open the extension popup from your browser toolbar.

  4. Join the room

    Paste the Room ID and choose Join Room. The default server is https://music.ytparty.my.id. Advanced / custom server is optional.

    Joining refreshes the music tab and may briefly interrupt playback.

  5. Share the guest invite

    Once the popup shows Connected, copy the guest invite link from Room info & settings. Friends open the link, choose a nickname, and can start requesting songs.

Prefer Telegram? Add @xmsc_bot to your group and send /register. Connect the extension with the Room ID it gives you, then search with @xmsc_bot and start playback with /play.

Room busy? Leave on the existing player before choosing Retry join. Joining never replaces that player. Get help with joining, multiple tabs, or unconfirmed admission.
