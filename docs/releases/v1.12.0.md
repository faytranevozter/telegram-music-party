# v1.12.0

## New
- Request features and report bugs from the extension popup, landing page, and support page through dedicated GitHub issue forms.
- Support faytranevozter on Saweria with a donation link and locally bundled profile QR code. The popup QR is collapsed by default; donations are optional and do not unlock features or guarantee requests.
- Optional authenticated private YouTube Music search service for backend song and room-authorized video queries. This integration is disabled by default and requires separate configuration and rollout verification.

## Fixed
- Default Telegram inline search to songs, with video results available through room-enabled `#video` queries.
- Bound private-search response processing with deadlines and response limits, and clarify missing/display-only metadata.
- Simplify artist display and extend search-result caching.

## Distribution
- No new extension permissions, remote QR services, payment SDKs, or payment collection inside the extension.
- The QR opens https://saweria.co/faytranevozter; it is not a QRIS payment code.
- Intended extension archive: `yt-music-party-extension-v1.12.0.zip`.
- Intended backend image tags after release automation: `ghcr.io/faytranevozter/telegram-music-party:1.12.0` and `ghcr.io/faytranevozter/telegram-music-party:1.12.0-sqlite`.
- Chrome Web Store review and public availability are separate from GitHub release publication.

## Release gates
- Verify the feature-request and bug-report URLs after the issue forms reach the default branch, before distributing the extension.
- Smoke-test the built extension against a real YouTube Music tab and Telegram room before publishing; automated popup tests do not replace end-to-end acceptance.
- Keep private search disabled until the ordinary HTTPS, deployment protection, costs/quotas, and real backend-network acceptance checks in `docs/backend-private-search.md` are complete. Preparing this release does not enable or deploy it.
- Pushing `v1.12.0` triggers GitHub release creation, backend image publishing, and Chrome Web Store submission. Do not push the tag until release approval. Pushing website changes to `main` separately triggers the existing Cloudflare deployment workflow.

Full changelog: https://github.com/faytranevozter/telegram-music-party/compare/v1.11.0...v1.12.0
