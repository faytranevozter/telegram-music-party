# v1.11.0

## New
- Join a music room directly from the extension popup, with custom server configuration and connection recovery.
- Refreshed extension popup, house-party landing page, screenshot gallery, and backend server homepage.

## Fixed
- Recover YouTube video search on cloud-hosted backends.
- Use the production music server by default while preserving saved custom server URLs.
- Keep room admission exclusive to one active device, including popup join recovery and room-busy feedback.

## Distribution
- Automated Chrome Web Store submission and provider-specific backend images.
- PostgreSQL: `ghcr.io/faytranevozter/telegram-music-party:1.11.0`.
- SQLite: `ghcr.io/faytranevozter/telegram-music-party:1.11.0-sqlite`.
- Chrome Web Store review and public availability are separate from GitHub release publication.
