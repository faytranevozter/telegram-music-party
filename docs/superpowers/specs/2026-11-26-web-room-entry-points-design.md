# Web room entry points

Give people a way to discover the browser-based room without making Telegram sound required. Keep the existing visual style, extension install link, and Telegram workflow.

Use a public **Open web room** link to `https://room.ytparty.my.id/` in the extension popup, landing page, and backend home page. This was chosen over a connected-room deep link: the extension’s player room ID is not a web invite, and the link must not carry room IDs or credentials.

Make the landing page web-first. Update the hero, page title, search and social descriptions, and shared-queue copy. Describe creating a web room, connecting the desktop YouTube Music player extension, and sharing a guest invite. Keep Telegram as an alternative setup path. Clarify that guests can request songs in their browsers without Telegram, but audio still plays only on the host’s YouTube Music tab.
